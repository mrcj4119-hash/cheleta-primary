# Project Overview

Cheleta SMS supports school administration, academic management, communication, attendance, and community reporting for Cheleta Primary School. The platform is designed to be mobile-first and suitable for demonstration to school stakeholders and community partners.

## Community Problem

The school needs a way to centralize learner information, communication, attendance records, and academic monitoring while remaining accessible on low-bandwidth mobile devices. The platform responds to this by providing a simple, practical school system with role-based access and offline attendance support.

## Proposed Solution

A responsive school management platform with separate roles for admin, teacher, parent, learner, school staff, Board of Management, and CSR partner. It includes school progress reporting, a grade-matched learning library, mentorship, student suggestions, and offline attendance recording.

## Development Approach

This prototype uses a lightweight Express backend and a React frontend. The design keeps the application easy to run locally while making it compatible with a future PostgreSQL-based production backend.
