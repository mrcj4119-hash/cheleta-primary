# CSR Project Narrative

Cheleta Primary School was selected as the focus institution because it represents a community school where digital school management can improve communication, learner support, and accountability without creating barriers for parents or teachers.

## Research and Findings

The project identified needs around attendance tracking, communication gaps, learner support, and access to digital learning resources. Teachers need a clear way to record attendance and update academic information. Parents need visibility into learner progress and announcements. CSR partners need aggregate impact data without sensitive child information.

## Proposed Technology Solution

The solution provides role-based access, offline capability, dashboards, and a communication hub so that the school can manage daily operations with a simple digital platform.

## Impact

The project demonstrates how digital tools can strengthen school administration, improve communication, and support resource planning in a low-resource setting while respecting privacy and maintaining a responsible CSR approach.
